## 审阅与验收边界

- 审阅每点归属是否回答目标概念的问题、必要表达与背景角色是否合适、暂缓原因及重评条件是否可操作。允许替代答案已随点保存，不以单一 slug 或措辞判错。
- 重点复核 EMFA k2 多归属、ReCast K15 暂缓是否必要，以及两篇“最佳”结论的条件差异。K15 可接受作为背景关联的替代，不能把挑选案例泛化为全类型覆盖。
- 四篇材料未确认存在可直接替换旧断言的真实跨论文冲突。真实冲突验收目前未满足；合成冲突案例仅用于独立离线测试，不能填补该缺口。
- 仅检查了已接受的 L2 与解析文本，未重新视觉核对 PDF 表格、公式和图。原文事实审阅与维护决策审阅应分别报告。
- 人工审阅后再按固定小样本运行真实模型内容验收，保留实际模型输出、失败、重试及人工分歧。程序通过、模型语义结果与人工通过分别记载。
