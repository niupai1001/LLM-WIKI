# 单遍编写与资讯补充

2026-10-11。用户反馈第二遍收益有限、首遍遗漏具体方法、资讯缺失。本轮覆盖此前“第二遍必须执行”的调用策略，保留独立 Rewrite 与人工发布保护。

- 默认一次模型调用。先输出带原文证据的核心断言，再写解释正文；额外表达编辑由复选框或 `--second-pass` 显式开启。JSON 格式错误可能重试。显式编辑失败及旧失败稿仍不能发布。
- 长文按章节和分布选段，记录提取文本字符范围；模型选择摘录编号，程序复制原文。没有新证据数据库或向量检索。摘录存在只能证明出处，不能判断语义支持或实验真实。
- 相似新资料优先更新既有概念及断言；来源详情“归入 Wiki”可指定页面。测试覆盖一条旧断言增加新来源并审核发布。自动匹配仍依赖词语排序和模型判断；每批只生成一个页面，不保证所有相关页面都更新。
- 去掉编辑说明，限制机械对立句式。只展示实际事实疑点、差异和证据。资料不足、比较组或方法适用范围不明确时仍需核对。
- 新增 LangChain 官方博客 RSS，OpenAI 资讯取消七天限制。四份补充材料已取得全文：Anthropic 构建 Agent、上下文工程文章，LangChain 规划智能体文章，OpenAI AgentKit 资讯。HTML 元数据补充 JSON-LD 及正文日期声明；归档原始 HTML 保留，提取文本过滤明确的订阅组件。

## 实际样稿的发现

两份新样稿保留待审，没有自动发布：

1. 规划与执行：提取了规划器、执行器、ReWOO 变量引用、LLMCompiler 任务依赖等具体过程。但首遍把三种架构描述为共有重新规划回路，原文并不支持这项泛化；已标记人工核查。

这些样稿说明第二次措辞编辑不能替代知识核查。新策略节省固定润色调用，把方法信息和引用完整性放在首遍；自然表达和正文语义准确性仍有改进空间。不要把模型的 `needs_fact_review=false` 当作通过审核。
