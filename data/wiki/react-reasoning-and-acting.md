# ReAct：把推理与行动接成能够更新的任务求解过程

ReAct 想检验的是：**模型能否在行动带来新信息后继续推理，又用推理决定下一步行动，从而更可靠地解决需要知识或连续操作的任务？** 这篇工作的贡献，是把两者放进同一条持续更新的轨迹，并用知识问答、事实核查、文字环境和购物网站四类任务检验它。结果支持这种结合的价值，但也揭示了一个关键限制：接入外部环境会改变错误的来源，不会自动使答案更准确。

## 为什么需要把两种能力接起来

作者面对的是两条各有缺口的路线。在论文比较的思维链（CoT）设置中，模型依据参数中的知识生成多步推理，却没有获取外部反馈的机会。它即使把推理顺序安排得合理，仍可能从一个错误事实出发，再把这个错误传给后续步骤。知识缺失或已经变化时，“多想几步”也未必能补回正确事实。

另一条路线让语言模型依据观测生成行动，例如搜索、打开页面或移动物品。但从很长的观测与动作历史直接预测下一步，可能需要隐含完成目标分解、事实抽取、状态追踪和异常处理。只有动作记录，并不保证模型正确区分“想要把物品洗净”与“物品已经洗净”，也不保证它能把搜到的几条事实组合成最终答案。作者因此希望加入一个可在上下文中读写的语言中间层，帮助模型组织当前知道什么、还缺什么、接下来该做什么。这一动机针对本文所比较的推理与行动路线。[S:e504ba1ba9c3fffc]（§1–2，pp.1–4）

这两个缺口是相互关联的。推理需要新事实，行动才能把事实带回来；行动又需要一个随反馈修订的目标与状态解释，否则模型可能拿着正确观测做出不合适的下一步。ReAct 的目的，就是检验这种双向联系是否能比单独推理或单独行动更有用。

## 核心回答：让文字思考参与控制，而让行动提供反馈

ReAct 在可执行动作之外，允许模型生成自由形式的“思考”（thought）。环境动作会带来新观测；思考本身不改变外部环境，而是被加入上下文，影响后续的思考和行动。因此，思考可以把散落在历史中的信息组织为下一步决策所需的内容：分解问题、提取观测中的关键事实、标记子目标完成、决定下一目标、解释失败并改写计划。这里的“记忆”是轨迹中的文字状态，不是另外训练出的记忆模块，也不能据此把生成文字等同于模型全部内部计算。[S:e504ba1ba9c3fffc]（§2，pp.3–4）

在知识任务中，这个过程通常是“思考—动作—观测”反复交替。例如，多跳问答不必一次猜出所有中间事实：模型先识别当前缺的关系，搜索得到一个实体，再依据返回内容决定查它的哪个属性；搜索名称不对时，也可以根据候选项更换查询。论文的 Wikipedia 环境允许搜索实体、在页面查找信息并提交答案，但每次返回内容有限。模型必须依据新证据判断还缺什么、下一步查什么。[S:e504ba1ba9c3fffc]（§3.1–3.2，pp.4–5；附录 C.1–C.2，pp.16–21）

在可能包含很多操作的交互任务中，作者不要求每次动作前都生成一段思考，而允许在重要节点稀疏地插入。例如，“已经拿到刀”应当引出“去水槽并清洗”，洗净的观测再引出“放到台面”，而不是把任务描述中的“干净的刀”误当作当前事实。这样的文字既指导探索，也连接前后子目标。论文主体主要使用冻结的 PaLM-540B，以人工编写的少量轨迹作为提示示例：HotpotQA 六例、FEVER 三例、ALFWorld 每次两例、WebShop 一例。贡献首先是组织任务求解过程的方法，并不以新增模型结构为前提。[S:e504ba1ba9c3fffc]（§2、§4，pp.3–4、7–8；附录 C–D）

这个设计为什么可能有效，可以分成两面理解：行动让推理获得参数知识之外的信息，思考则把新信息转成后续决策依据。但“为什么可能有效”还不是“已经证明有效”；要看实验是否分别显示了这两面的作用。

## 实际结果：交互决策收益清楚，知识问答存在权衡

### 外部事实使轨迹更有依据，却没有让所有问答分数上升

HotpotQA 要跨 Wikipedia 内容完成多跳问答，FEVER 要判断陈述被支持、被反驳还是信息不足。两者在本文均只给问题或陈述，不预先给支持段落。下表保留能比较核心回答的 PaLM-540B 提示结果；HotpotQA 使用答案精确匹配率（EM），FEVER 使用分类准确率，均以百分数计。[S:e504ba1ba9c3fffc]（表1，p.5）

| 方法 | HotpotQA EM | FEVER 准确率 |
| --- | ---: | ---: |
| 只有行动与观测的 Act | 25.7 | 58.9 |
| 只有内部推理的 CoT | 29.4 | 56.3 |
| CoT 自一致性投票（CoT-SC） | 33.4 | 60.4 |
| ReAct | 27.4 | 60.9 |
| ReAct 达到步数上限仍未作答时转 CoT-SC | 35.1 | 62.0 |
| CoT-SC 缺乏多数支持时转 ReAct | 34.2 | 64.6 |

ReAct 在两个任务都优于 Act，说明在已有行动和观测之外，显式思考仍能帮助组织求解。但它相对 CoT 的方向并不一致：FEVER 提升了 4.6 个百分点，HotpotQA 低了 2.0 个百分点。因此，论文不能支持“ReAct 单独使用就普遍超过思维链”的结论。外部信息对于需要辨别具体事实的核查很有价值，多跳问答却还受到检索是否找到有效信息、推理能否摆脱错误路线等因素限制。

错误分析解释了这种分数背后的差异。作者的人工轨迹分析发现，CoT 更容易包含虚构事实，ReAct 的过程则更有外部依据；但 ReAct 的失败样本中，推理错误和缺乏有效搜索结果分别占 47% 与 23%，包括无法摆脱重复的思考与行动。这表明，外部依据能缓解事实虚构，却把一部分难题转移到“能否找对信息、读对信息、及时改变路线”。[S:e504ba1ba9c3fffc]（§3.3、表2，p.6）

此外，两种方法都出现了答案与标注匹配、过程却有错误的轨迹。答案成绩与事实、推理质量需要分开看：答对不保证过程正确，减少幻觉也不保证整项任务更准确。[S:e504ba1ba9c3fffc]（表2；附录 E.1，pp.32–33）

### 两种知识来源组合，比要求一种方式承担全部任务更有效

作者没有停在单一 ReAct 上，而尝试让它与 CoT-SC 互相补位。第一种策略在 ReAct 达到规定步数上限仍未作答时转向 CoT-SC，HotpotQA 与 FEVER 的上限分别是七步、五步；第二种策略先采样若干 CoT 答案，如果最高票答案出现次数少于样本数的一半，则调用 ReAct。CoT-SC 的表1结果使用 21 条采样轨迹。两种策略分别用“达到步数上限仍未作答”和“内部答案不一致”作为切换信号。[S:e504ba1ba9c3fffc]（§3.2，pp.5–6）

两种组合分别取得表中两个任务的最高提示成绩，且在图2比较的不同采样次数下均优于单独的 CoT-SC。作者报告，组合用约三至五条 CoT 样本即可达到单独 CoT-SC 使用 21 条样本时的表现。这支持内外知识具有互补性，但不能把 CoT 样本数减少直接算作总成本下降，因为组合还会产生额外的检索、思考和环境交互。选择哪一方向先行也与任务有关：本文没有找到一个在两个任务中同时最优的固定顺序。[S:e504ba1ba9c3fffc]（§3.3、图2，pp.5–6）

### 在连续操作中，思考帮助维持“目标—当前状态—下一步”的关系

ALFWorld 是文字化家庭环境，模型要通过移动、拿取、清洗等操作完成六类任务，可能需要几十步。作者在 134 个未见评估游戏上测试；每类任务的三个示例中，每次取两个并改变顺序，组成六组提示。ReAct 六组提示的平均成功率是 57%，最好一组为 71%；Act 最好一组为 45%，论文采用的 BUTLER 基线最好结果为 37%。摘要中的 34 个百分点提升，指的是 ReAct 最好结果与 BUTLER 最好结果的差，而不是 ReAct 的平均成绩。即使最差的 ReAct 提示组也达到 48%，高于这两个比较对象的最好结果，说明收益并非只出现于一个幸运提示。[S:e504ba1ba9c3fffc]（§4、表3，pp.7–8）

WebShop 则要求在含真实商品文本的研究环境中，通过搜索、浏览、选规格和模拟购买满足用户要求。在 500 条测试指令上，一例提示的 ReAct 成功率为 40.0%，Act 为 30.1%，IL 与 IL+RL 为 29.1% 和 28.7%。平均属性满足得分从 Act 的 62.3 提高至 66.6；“全部要求都满足”的成功率提升了 9.9 个百分点，幅度更明显。作者观察到，思考有助于把混杂的标题、选项和用户要求对应起来。人类成功率仍为 59.6%，因此这不是对真实电商自主完成能力的充分证明。[S:e504ba1ba9c3fffc]（§4、表4，pp.7–8）

这两类结果都支持：已有环境反馈，并不意味着模型已正确理解进度；把进度、子目标转换和下一步依据写出来可以产生实际收益。ReAct 还优于作者构造的 ReAct-IM 对照，后者主要重复当前待完成目标；但这个对照同时改变了思考的内容和密度。因此，结果更适合支持“思考需要组织状态、目标与行动”，不能单独证明“越稀疏越好”，也不等于对原始 Inner Monologue 系统的完整比较。[S:e504ba1ba9c3fffc]（§4，p.8；附录 B.2、C.4、D.2，pp.15、23–30）

### 这种过程需要模型学会，少样本提示并非总是足够

作者用模型生成、最终答案正确的 3,000 条轨迹微调较小的 PaLM-8B/62B。仅靠提示时，ReAct 在这两个规模上反而是四种格式中最弱的；微调后，它在同规模比较中变成最强。原文还报告，微调后的 8B ReAct 超过图3比较的所有 62B 提示方法，62B ReAct 超过其中所有 540B 提示方法；图3比较的是 Standard、CoT、Act 和 ReAct 四种格式，不包含前述组合策略。[S:e504ba1ba9c3fffc]（§3.2–3.3、图3，pp.5–7）

这表明，“模型会说自然语言”与“模型能通过几个示例稳定掌握推理、行动和观测的联合过程”是两回事。交互轨迹可以成为学习对象，外部知识访问能力也不必完全依靠增加参数规模。作者将其解释为：学习如何访问知识，比记住问答事实更易泛化；本研究观察与此相容，但实验还不足以把性能差异唯一归因为这个机制。其余提示成绩与论文列出的监督式领域最好成绩仍有明显距离，规模化高质量轨迹训练是后续方向，而不是本文已经完成的结果。

## 这项工作留下的四项可复用知识

**K1｜在需要多步交互的任务中，语言中间状态可以把目标、已观察状态和下一步行动连接起来；其作用取决于它是否组织决策信息。**

ReAct 对 Act 的收益横跨四类任务，ALFWorld 和 WebShop 的成功率尤其直接检验了行动是否完成目标。结合方法设计和附录轨迹，可以把它理解为：显式思考给下一步预测提供了已经整理过的上下文，降低每次都从完整历史重新推断子目标与进度的负担。这个解释由对照结果支持，但论文没有分别测量每种思考功能的独立因果贡献。

可迁移的认识不是“给每步加一句解释”，而是让中间文字承担确定的工作：识别信息缺口、更新完成状态、决定目标转换或改变探索方向。ReAct-IM 的结果使这一点更具体，也提醒我们不能把文字出现的次数当成有效思考。适用范围首先是本文这种文字观测、有限动作、可持续保留轨迹的环境；它不保证长到任意长度的历史都能被模型正确利用。

这种显式中间层还提供了检查和干预的入口。附录展示，人工修改两处思考就能把一条失败的 ALFWorld 轨迹引向成功。这说明思考文字在该例中能影响后续行为；它尚不能证明这种干预普遍可靠，更不能证明模型写出的每句话都是对内部计算的忠实说明。[S:e504ba1ba9c3fffc]（依据：§2、表1、表3–4；附录 A.3、B.2、D.2）

**K2｜外部证据可以减少内部事实虚构，但系统可靠性仍取决于检索、证据解释和行动控制；错误可能转移而非消失。**

这一判断同时来自两组看似相反的结果：人工抽样显示 ReAct 的事实依据更好，而 HotpotQA 总体 EM 并未超过 CoT。两者并不矛盾，因为“减少幻觉”只解决了错误链条的一部分。有限检索接口可能找不到关键事实，模型也可能沿着无用搜索反复行动，或把得到的事实放进错误推理结构。

因此，选用外部知识方案时，值得分别检查信息有没有取得、证据是否相关、推断是否成立、过程能否结束。仅凭最终答对率或一条看似流畅的轨迹都不足以判断全过程。这个认识适用于本文所检验的知识密集任务与接口；不能据此断言换成更强检索器后的结果，也不能把按成功/失败抽样的比例当作总体风险估计。[S:e504ba1ba9c3fffc]（依据：表1–2；附录 D.1、E.1）

**K3｜参数中的知识与交互取得的证据可以互相补位，按失败迹象切换路线是可行的组合方式，但切换信号本身仍需要验证。**

组合成绩说明，ReAct 达到步数上限仍未作答时，内部知识仍可能给出答案；内部答案彼此分散时，搜索又能提供新的事实约束。这比要求模型在所有问题上固定使用一种知识来源更有弹性，也是从“有工具”走向“何时用工具”的一步。

本项工作支持的是两条具体启发式在指定数据和模型上的收益。样本多数不足一半不是真实置信度的校准证明，达到步数上限仍未作答也不等于内部知识一定可靠。后续将这个认识用于系统设计时，应把切换策略连同效果与资源开销一起评估，而不是把七步、五步或半数阈值当成通用常数。[S:e504ba1ba9c3fffc]（依据：§3.2–3.3、表1、图2）

**K4｜联合推理与行动是一种需要学习的程序能力；较小模型的少样本失败，不足以说明它无法通过交互轨迹学会这种能力。**

小模型中提示与微调的排序反转，是这一知识最直接的依据。任务格式更复杂时，单靠提示同时学会计划、接口使用和证据利用可能很难；把成功轨迹变成训练数据后，同样的格式却表现出优势。因此，模型大小、提示方式与轨迹训练必须一起看，不能把某一提示结果当作能力上限。

这为“训练模型如何取得并使用知识”提供了实证入口，但仍是 HotpotQA 上的初步结果。筛选时依据最终答案正确，不保证每条中间推理都正确；论文也未在这里证明可跨任意工具或环境迁移。值得积累的是“交互过程本身可以学习，以及学习方式会改变能力表现”这一判断，而不是从一次比较推导出外部知识访问训练普遍优于事实学习。[S:e504ba1ba9c3fffc]（依据：§3.2–3.3、图3、附录 B.1）
